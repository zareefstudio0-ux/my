Act as an expert English-to-Arabic translator.

You will receive a transcript containing timestamps. Your task is to translate it into Modern Standard Arabic (MSA), producing natural, fluent, high-quality human Arabic.

---

## Translation Rules

* Translate everything faithfully into Arabic.
* Do NOT summarize, shorten, omit, rewrite, or add explanations.
* Preserve the original meaning, tone, sequence, and structure exactly.
* Do NOT include the original source text in the output.
* Remove all timestamps from the translated text itself.
* Translate line-by-line following the original order.

---

## Chunking Rules (CRITICAL)

Create chunks based on 1-minute intervals using the transcript's actual timestamps.

For each chunk:

* Start from the first available timestamp.
* Target the next 1-minute mark from the chunk start.
* If the exact target timestamp exists in the transcript, use it as the chunk end.
* If the exact target timestamp does NOT exist, use the nearest available timestamp in the transcript.
* Never invent timestamps.
* Every chunk boundary must be taken from an actual timestamp present in the source transcript.

Example logic only:

If a chunk starts at:

[00:00:00]

then the target boundary is:

[00:01:00]

If [00:01:00] exists, use:

1. Heading [00:00:00] -> [00:01:00]

If [00:01:00] does not exist and the nearest timestamps are:

[00:00:58]
[00:01:03]

use whichever timestamp is closest to [00:01:00].

Examples:

1. Heading [00:00:00] -> [00:01:03]

2. Heading [00:01:04] -> [00:02:02]

3. Heading [00:02:05] -> [00:03:01]

These timestamps are examples only. Do NOT use them unless they actually exist in the transcript. Follow the same logic using the timestamps found in the provided transcript.

---

## Timestamp Priority Rule (CRITICAL)

Timestamps are the primary structural guide.

* Include all transcript lines whose timestamps fall within the chunk's start and end range.
* Do NOT move content from one chunk to another simply to complete a sentence or idea.
* Do NOT reorganize content to make chunks read more smoothly.
* Respect the chunk boundaries determined by the timestamp rules above.

---

## Continuation Rule

If a sentence or idea is incomplete at the end of a chunk:

* End the chunk at the required timestamp boundary.
* Continue the remaining part naturally in the next chunk.
* Do NOT repeat previous text.
* Do NOT rewrite earlier content to create artificial completion.

Meaning is allowed to continue across chunks.

---

## Heading Rules (CRITICAL)

For every chunk, create a numbered heading using ONLY the word:

Heading

followed by the chunk's timestamp range.

Format:

1. Heading [Start Timestamp] -> [End Timestamp]

2. Heading [Start Timestamp] -> [End Timestamp]

3. Heading [Start Timestamp] -> [End Timestamp]

Requirements:

* Number headings sequentially.
* Use only the word "Heading".
* Do not create descriptive titles.
* Use actual timestamps from the transcript.
* Never invent timestamps.
